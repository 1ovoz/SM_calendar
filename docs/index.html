SM Calendar

Google 캘린더와 동기화되는 가벼운 Windows 바탕화면 달력 위젯

SM Calendar 는 바탕화면에 월간 달력을 띄우고, 사용자의 Google 캘린더 일정을 보여 주며 추가·수정·삭제할 수 있게 해 주는 개인용 Windows 프로그램입니다. 광고가 없고, 별도 서버 없이 사용자의 PC 에서만 동작합니다.

기능

  • 바탕화면에 고정되는 반투명 월간 달력
  • Google 캘린더 일정 보기, 추가, 수정, 삭제
  • 여러 캘린더 표시/숨기기, 공휴일 표시
  • 오프라인일 때 마지막으로 받은 일정 표시

Google 데이터 사용

SM Calendar 는 사용자가 직접 Google 계정으로 로그인해 허용한 경우에만 Google Calendar API 를 사용하며, 일정을 표시하고 사용자가 요청한 변경을 반영하는 용도로만 사용합니다. 자세한 내용은 개인정보처리방침을 참고하세요.
