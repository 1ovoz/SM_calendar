# SM Calendar

Google 캘린더와 양방향 동기화되는 가벼운 Windows 바탕화면 달력 위젯입니다. Me Calendar 를 참고해 만들었고, 광고가 없습니다.

- **위젯 4종**: 월간 캘린더, 미니 월간 캘린더, 미니 어젠다(일정 목록 + 작은 달력), 미니 앱(작은 달력 + 일정 목록). 메뉴의 **위젯 변경**으로 형태를 바꾸며, 종류별 크기를 기억합니다.
- **글꼴**: 무료 글꼴 [Pretendard](https://github.com/orioncactus/pretendard)(SIL OFL)를 앱에 포함. 설정에서 맑은 고딕으로 바꿀 수 있습니다.
- **가벼움**: .NET 10 WinForms를 쓰고, 컨트롤 없이 레이어드 창에 직접 그립니다. 상태가 바뀔 때만 다시 그려서 대기 중에는 CPU를 거의 쓰지 않습니다. 외부 라이브러리(NuGet 패키지)를 하나도 쓰지 않습니다.
- **트레이 대기 모드**: 위젯을 모두 끄면 창을 전부 해제하고 동기화를 멈춘 뒤 메모리를 정리해서, 작업 표시줄 오른쪽 아래 트레이 아이콘만 남습니다. 아이콘을 클릭하면 다시 켜집니다. 꺼진 상태로 부팅하면 일정 캐시도 읽지 않습니다.
- **바탕화면 고정 / 항상 위**: 기본은 다른 창 아래에 깔리고 Win+D(바탕화면 보기)에도 사라지지 않습니다. 핀 버튼을 누르면 항상 위에 표시됩니다.
- **읽기/쓰기**: 편집 창에서 제목, 색상, 날짜·시간(종일), 반복(매일·매주·매월·매년·주중, 종료일/횟수), 알림(최대 5개), 장소, 메모, 캘린더를 설정합니다. 반복 일정은 "이 일정만" 또는 "모든 반복 일정"을 골라 수정·삭제합니다.
- **빠른 부팅**: 마지막으로 받은 일정을 암호화해서 캐시해 두기 때문에, 네트워크가 연결되기 전에도 바로 표시합니다. 네트워크가 없으면 15초부터 최대 5분 간격으로 자동 재시도합니다.

## 사용법

| 동작 | 방법 |
|---|---|
| 위젯 형태 바꾸기 | 위젯 우클릭(또는 `⋯`) / 트레이 아이콘 우클릭 → **위젯 변경** |
| 위젯 끄기 / 켜기 | 위젯의 `✕` → 트레이로. **트레이 아이콘 클릭**으로 다시 켜기 |
| 접기 / 펼치기 | 위젯의 `—` 버튼 (머리글만 남김) |
| 항상 위에 표시 | 위젯의 핀 버튼 (켜지면 파란색) |
| 배경 투명도 · 글자 크기 | 위젯의 팔레트 버튼, 또는 **Ctrl + 마우스 휠**(투명도). 글자를 키우면 위젯도 같은 비율로 커집니다 |
| 새 일정 | 날짜를 **더블클릭**, `+` 버튼, 미니 앱의 날짜별 `+` |
| 일정 수정/삭제 | 일정을 **클릭** |
| 하루 일정 전체 보기 | 날짜 숫자나 `+N개` 클릭 (미니 월간은 날짜 클릭) |
| 이전/다음 달 | 제목 양옆 `‹ ›` 버튼 또는 **마우스 휠** (일정 목록 위에서는 휠로 스크롤) |
| 연·월 바로 이동 | 제목(`2026년 10월`)을 클릭 → 연도 `‹ ›` / 월 선택 |
| 오늘로 이동 | 제목 옆 **오늘** 버튼 |
| 이동 / 크기 조절 | 빈 곳이나 제목을 드래그 / 오른쪽 아래 모서리 점을 드래그 |
| 지금 동기화 | 월간 위젯 아래 상태 글씨 클릭, 또는 메뉴 |
| 편집기에서 저장 / 닫기 | `Ctrl+Enter` / `Esc` |
| 시간 입력 | 시간 칸을 클릭해 목록에서 고르거나 `930`, `14:30` 처럼 직접 입력 |

오른쪽의 `+`, 팔레트, 핀, 접기, `⋯`, `✕`(항상 맨 끝) 버튼은 마우스를 위젯에 올렸을 때만 나타납니다.

메뉴의 **설정**에서 테마(어두운/밝은), 글꼴, 주 시작 요일, 동기화 주기, Windows 시작 시 실행, 표시할 캘린더를 바꿀 수 있습니다.

처음 실행하면 **Windows 시작 시 실행이 자동으로 켜집니다**. 끄려면 메뉴에서 해제하세요.

## Google 연동 설정 (최초 1회)

Google 은 개인 앱에도 OAuth 클라이언트를 요구하기 때문에, 본인 Google Cloud 프로젝트에서 클라이언트를 하나 만들어야 합니다. 비용은 들지 않습니다.

1. <https://console.cloud.google.com/> 에서 새 프로젝트를 만듭니다. 예: `SM Calendar`
2. **API 및 서비스 → 라이브러리**에서 `Google Calendar API` 를 검색해 **사용**을 누릅니다.
3. **Google 인증 플랫폼(OAuth 동의 화면)**에서 **시작하기**를 누르고 다음을 입력합니다.
   - 앱 이름, 사용자 지원 이메일
   - 대상: **외부(External)**
   - 연락처 이메일
4. **대상(Audience)** 화면에서 **앱 게시(Publish app)**를 눌러 상태를 **프로덕션**으로 바꿉니다.
   - ⚠️ "테스트" 상태로 두면 Google 이 로그인을 **7일마다 만료**시킵니다.
   - 프로덕션으로 바꾸면 로그인할 때 "확인되지 않은 앱" 경고가 뜹니다. 본인만 쓰는 앱이므로 **고급 → (앱 이름)(으)로 이동**을 눌러 진행하면 됩니다.
5. **클라이언트(Clients) → 클라이언트 만들기**로 이동합니다.
   - 애플리케이션 유형을 **데스크톱 앱**으로 고르고 만듭니다.
   - **JSON 다운로드**를 눌러 파일을 받습니다 (`client_secret_….json`).
6. 위젯 아래쪽의 **구글 계정 연결하기**를 클릭하고, 받은 JSON 파일을 선택합니다.
7. 브라우저에서 로그인한 뒤 권한을 허용하면 연결이 끝납니다.

요청하는 권한은 일정 읽기/쓰기(`calendar.events`)와 구독 중인 캘린더 목록 보기(`calendar.calendarlist.readonly`), 두 가지뿐입니다.

## 다른 PC 에서 쓰기 (Windows)

1. 그 PC 에 **.NET 10 Desktop Runtime (x64)** 을 설치합니다. <https://dotnet.microsoft.com/download/dotnet/10.0> → ".NET Desktop Runtime" → Windows x64. (설치 안 된 상태로 실행하면 Windows 가 다운로드 링크를 띄웁니다.)
2. `SMCalendar-<버전>-win-x64.zip` 을 풀어서 원하는 폴더에 둡니다. 권장: `%LOCALAPPDATA%\Programs\SMCalendar`
3. `SMCalendar.exe` 를 실행합니다. 시작 메뉴 바로가기와 시작 시 자동 실행이 자동으로 등록됩니다.
4. **구글 계정 연결하기** → 이 PC 의 `%APPDATA%\SMCalendar\client_secret.json` (또는 처음에 받은 `client_secret_….json`) 을 USB 등으로 옮겨서 선택 → 브라우저 로그인.

- Google Cloud 설정은 다시 할 필요 없습니다. 같은 OAuth 클라이언트 파일을 여러 PC 에서 써도 됩니다.
- 로그인 정보(`token.dat`)는 그 PC·그 Windows 계정에서만 풀리도록 암호화되어 있어 **복사해도 쓸 수 없습니다.** PC 마다 한 번씩 로그인하세요.
- `client_secret` 파일은 공개 저장소나 메신저에 올리지 마세요 (zip 에는 포함하지 않았습니다).
- 인터넷에서 받은 zip 이면 처음 실행할 때 SmartScreen("Windows 의 PC 보호") 경고가 뜰 수 있습니다. 서명하지 않은 개인 프로그램이라 그렇고, **추가 정보 → 실행** 을 누르면 됩니다.

### 제거

트레이 → 종료 → 설정의 "Windows 시작 시 실행" 해제(또는 종료 전에) → 설치 폴더, `%APPDATA%\SMCalendar`, 시작 메뉴의 `SM Calendar` 바로가기를 삭제합니다.

## 빌드 / 설치

WSL 에서 빌드합니다. .NET 10 SDK 가 `~/.dotnet` 에 있어야 합니다.

```bash
./build.sh            # 빌드 → %LOCALAPPDATA%\Programs\SMCalendar 에 설치 → 실행
./build.sh --demo     # 로그인 없이 샘플 일정으로 실행
./build.sh --release  # 다른 PC 용 zip 만들기 (release/ 폴더)
```

Windows 에서 직접 빌드하려면 다음 명령을 씁니다.

```powershell
dotnet publish -c Release -o dist
```

실행에는 .NET 10 Desktop Runtime 이 필요합니다. 이 PC 에는 이미 설치되어 있습니다.

## 파일 위치

데이터는 `%APPDATA%\SMCalendar\` 에 저장됩니다.

| 파일 | 내용 |
|---|---|
| `settings.json` | 위젯 종류·위치·크기·모양, 전체 설정 |
| `cache.dat` | 일정 캐시 (오프라인·부팅 직후 표시용). DPAPI 로 암호화 |
| `token.dat` | Google refresh token. DPAPI 로 암호화되어 현재 Windows 사용자만 복호화 가능 |
| `client_secret.json` | 가져온 OAuth 클라이언트 |

## 팁

- Windows 는 시작 프로그램을 로그인 후 몇 초 늦게 실행합니다. 이 지연을 없애려면 아래 레지스트리 값을 추가합니다.
  - 키: `HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\Serialize`
  - 값: `StartupDelayInMSec` (DWORD) = `0`
- 대한민국 공휴일을 빨간 날로 표시하려면 Google 캘린더에서 **"대한민국의 휴일"** 캘린더를 구독하세요.

## 보안

| 위험 | 대응 |
|---|---|
| 네트워크 중간자 공격(HTTPS 가로채기) | TLS 1.2/1.3 만 허용. Windows 인증서 검증에 더해, Google 이 공개한 루트 인증서([pki.goog](https://pki.goog/roots.pem)) 로 서명된 연결만 허용(인증서 고정). PC 에 몰래 설치된 가짜 루트 인증서로는 가로챌 수 없음. 리디렉션 따라가기 꺼짐 |
| 로그인 과정 가로채기 | PKCE(S256) + 무작위 state 확인. 로그인 응답을 받는 임시 포트는 127.0.0.1 에만 열리고(외부 접근 불가), 로그인하는 최대 5분 동안만 열림. state 가 다른 요청은 무시, 요청 크기 8KB·연결당 10초 제한 |
| 토큰·일정 유출 | refresh token 과 일정 캐시를 DPAPI 로 암호화. 다른 Windows 계정이나 디스크를 떼어 간 경우 읽을 수 없음. 로그아웃하면 토큰을 Google 에서 폐기하고 캐시 삭제 |
| 과도한 권한 | 일정(`calendar.events`) + 캘린더 목록 보기(`calendar.calendarlist.readonly`) 만 요청. 메일·드라이브 등 다른 Google 데이터에는 접근 권한이 없음 |
| 악성 일정 내용 | 일정 제목·메모는 글자로만 그림(HTML/스크립트 실행 없음). "Google 캘린더에서 열기" 는 `https://*.google.com` 주소만 열도록 제한 |
| 공급망 | 외부 패키지 0개. Microsoft .NET 런타임과 Windows API 만 사용 |
| 권한 상승 | 관리자 권한 없이 현재 사용자 권한으로만 실행. 외부에서 접속할 수 있는 포트를 열지 않음 |

**한계**: 같은 Windows 계정으로 이미 실행 중인 악성 프로그램은 DPAPI 로 암호화된 토큰도 풀 수 있습니다(브라우저 쿠키·비밀번호와 같은 수준). 이건 앱이 막을 수 없으니 백신과 Windows 업데이트를 유지하세요. 회사망처럼 HTTPS 를 검사하는 프록시 환경에서는 인증서 고정 때문에 동기화가 차단됩니다.

